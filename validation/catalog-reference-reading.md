# Lectura de referencia visual del catálogo

La imagen original mide 1154 × 164 píxeles y tiene una relación panorámica aproximada de 7.04:1. Se revisaron dos segmentos horizontales en orden de izquierda a derecha.

La referencia muestra tres filas compactas de filtros con etiquetas pequeñas alineadas a la izquierda: “Aplicaciones”, “Marcas” y “Grupos”. Cada fila combina un botón seleccionado con fondo verde o azul y opciones secundarias en texto claro sobre fondo azul marino. La segunda fila incluye “Todas las Marcas”, “DT Spare Parts” y “SIEGEL Automotive”. La tercera fila incluye “Todas las Piezas” y grupos como Bujes y ruedas, Cabina, Caja de cambios, Carrocería, Dirección, Ejes, Embrague y pedal, Motor, Partes universales / Accesorios, Sistema de combustible, Sistema de escape y Sistema de freno. En el segundo segmento continúan Sistema de refrigeración, Sistema eléctrico, Suspensión y Árbol de transmisión.

Aplicación para el ajuste: aumentar la tipografía de filtros y datos de artículos sin perder la densidad organizada; conservar agrupación por filas, contraste oscuro y separación suficiente para uso táctil y responsive.
